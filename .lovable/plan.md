# تحسين قالب Telegram لمحاذاة RTL صحيحة

## المشكلة في القالب الحالي
- كل حقل مقسّم على سطرين (تسمية ثم قيمة)، مما يُضعف اتجاه RTL.
- الرموز التعبيرية (emojis) في بداية السطر تُعالج Telegram أحياناً كـ LTR، فتكسر المحاذاة.
- عدم وجود فاصل واضح بين التسمية والقيمة يجعل القراءة غير طبيعية.

## الحل المقترح
سطر واحد لكل حقل، يبدأ بـ RTL Mark (`\u200F`)، ويستخدم ترتيب "التسمية: القيمة".

## قالب محسّن (نسخة منظمة)
```text
\u200F━━━━━━━━━━━━━━━━━━━━
\u200F🛍️ المنتج: <b>{name}</b>
\u200F━━━━━━━━━━━━━━━━━━━━

\u200F🏷️ العلامة التجارية: <b>{brand}</b>
\u200F🔖 رقم الموديل: <code>{model}</code>
\u200F🆔 كود المنتج: <code>{code}</code>
\u200F💰 السعر: <b>{price}</b>
\u200F📦 المتوفر: <b>{stock}</b>

\u200F📝 الوصف:
\u200F{description}
```

## قالب بديل (أكثر تركيزاً على التسويق)
```text
\u200F✨ <b>{name}</b> ✨

\u200F🏷️ {brand} · 🔖 {model}
\u200F💰 <b>{price}</b> · 📦 متوفر {stock}

\u200F📝 {description}

\u200F🆔 <code>{code}</code>
```

## نصائح إضافية
1. دائماً ابدأ كل سطر بـ `\u200F` (أو الصق الرمز المنقوط من اليمين).
2. إذا أردت سطراً فاصلاً، ضع قبله `\u200F` أيضاً.
3. تجنب وضع أرقام أو أكواد في نهاية السطر بدون تسمية واضحة؛ استخدم `<code>` لتحسين القراءة.
4. لا تعتمد على `dir="rtl"` في HTML لـ Telegram — الأكثر موثوقية هو RTL Mark لكل سطر.
